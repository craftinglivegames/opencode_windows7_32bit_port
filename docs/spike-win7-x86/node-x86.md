# Node x86 на Windows 7 x64/x86 — фактические результаты

Дата: 2026-11-05. Проверка на нетбуке 192.0.2.20 (Windows 7 Ultimate 32-bit).

| Версия Node (win-x86) | Запуск на Win7 x86 | Вывод |
|---|---|---|
| Node 12.22.7 | **да** | `v12.22.7`, exit code 0 |
| Node 22.23.4 (официальная) | **нет** | `%1 не является приложением Win32` (бинарник требует Win10 API) |

## Вывод

- Официальные x86-сборки Node 22 **не запускаются** на Windows 7: ошибка загрузчика «не является приложением Win32».
- Node 12.22.7 — последняя официальная версия, которая реально работает на Win7 x86.
- Node 12 слишком старая для opencode 1.19.3 (Effect, современные зависимости, ESM-фичи).
- Единственный путь к Node 20/22 на Win7 — **сторонние бэкпорты** (например, проект с Habr «Node.js 22 и Windows 7»). Официальной поддержки нет, стабильность не гарантирована.

## Что это значит для порта

Локальный сервер opencode на Node требует как минимум Node 20+.
На Win7 x86 это возможно только через неофициальный бэкпорт — риск для конечных пользователей.
